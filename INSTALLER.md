# 📥 PumbaNET Client - Готовый установщик

## Самый простой способ

### 1. Скачайте APK файл

Перейдите на страницу **Releases** и скачайте последний APK:
👉 https://github.com/Fortumers/pumbanet-client/releases

Или используйте прямую ссылку на последнюю версию.

### 2. Установите на Android

1. **Откройте скачанный файл** на телефоне
2. **Разрешите установку** (если спросит)
3. **Нажмите "Установить"**
4. **Запустите приложение**

Всё! 🎉

## Если хотите собрать сами

### На Windows

1. Откройте командную строку в папке с проектом
2. Выполните:
   ```cmd
   gradlew.bat assembleDebug
   ```
3. APK появится здесь:
   ```
   app\build\outputs\apk\debug\app-debug.apk
   ```

### На Mac/Linux

1. Откройте терминал в папке с проектом
2. Выполните:
   ```bash
   chmod +x build-installer.sh
   ./build-installer.sh
   ```
3. APK появится здесь:
   ```
   app/build/outputs/apk/debug/app-debug.apk
   ```

## Как установить APK на телефон

### Шаг 1: Разрешите установку

**Android 8+**:
- Настройки → Приложения → Специальный доступ → Установка неизвестных приложений
- Выберите ваш браузер или файловый менеджер
- Включите переключатель

**Android 7 и ниже**:
- Настройки → Безопасность → Неизвестные источники ✓

### Шаг 2: Установите

1. Откройте файловый менеджер
2. Найдите файл `app-debug.apk`
3. Нажмите на него
4. Нажмите "Установить"
5. Готово!
