# 📥 Скачать PumbaNET Client

## Готовый APK для установки

### Способ 1: GitHub Releases (рекомендуется)

1. Перейдите на страницу Releases:  
   👉 **https://github.com/Fortumers/pumbanet-client/releases**

2. Скачайте последний файл `PumbaNET-debug.apk`

3. Установите на Android устройство

### Способ 2: Собрать самостоятельно

Если хотите собрать APK сами:

```bash
# Клонировать репозиторий
git clone https://github.com/Fortumers/pumbanet-client.git
cd pumbanet-client

# Собрать APK
./gradlew assembleDebug

# APK будет здесь:
# app/build/outputs/apk/debug/app-debug.apk
```

## 📱 Установка

### Шаг 1: Разрешите установку из неизвестных источников

**Android 8+**:
1. Настройки → Приложения → Специальный доступ
2. "Установка неизвестных приложений"
3. Выберите ваш браузер или файловый менеджер
4. Включите переключатель

**Android 7 и ниже**:
1. Настройки → Безопасность
2. Включите "Неизвестные источники"

### Шаг 2: Установите APK

1. Откройте файловый менеджер
2. Найдите скачанный файл `PumbaNET-debug.apk`
3. Нажмите на файл
4. Нажмите "Установить"
5. Дождитесь завершения

### Шаг 3: Запустите приложение

1. Найдите иконку PumbaNET
2. Нажмите для запуска
3. Предоставьте разрешения (VPN, камера для QR)

## 🔧 Требования

- **Android**: 8.0 или новее (API 26+)
- **Место**: 50MB+
- **RAM**: 2GB+ (рекомендуется)
- **Архитектура**: ARM64 (большинство современных устройств)

## ❓ Troubleshooting

### "App not installed"

**Причина**: Конфликт с предыдущей версией

**Решение**:
1. Удалите старую версию PumbaNET
2. Перезагрузите устройство
3. Установите заново

### "Parse error"

**Причина**: Файл скачан не полностью

**Решение**:
1. Скачайте APK заново
2. Проверьте размер файла (~15-20MB)

### "Insufficient storage"

**Причина**: Недостаточно места

**Решение**:
1. Освободите минимум 100MB
2. Очистите кэш
3. Попробуйте снова
